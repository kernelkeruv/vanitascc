Connect supported Bluetooth LE devices

Choose your own nearby device. Read a standard battery level or, with separate consent, live heart rate. No uploads, tracking, accounts, or background scans.

Browser limitation: Chrome on Android supports Web Bluetooth for many BLE peripherals. iPhone Safari does not. Bluetooth audio headphones use the operating system's audio connection, not Web Bluetooth. Ray-Ban Meta glasses require Meta's official native SDK for sensor or camera access.

Beyond the browser

Android companion

Kotlin BluetoothGatt + Nearby Devices permissions for robust BLE discovery and access. Native APIs for media routing and notifications.

iPhone companion

Swift Core Bluetooth for BLE and AVAudioSession for audio routing. Web Bluetooth is unavailable in Safari.

Ray-Ban Meta

Use Meta Wearables Device Access Toolkit in an approved iOS or Android app. Supported features vary by glasses model and permissions.

Other IoT

Adapter plugins for explicitly supported GATT services or vendor APIs. MQTT belongs behind authenticated backend gateways, never exposed as open public controls.
